# 📝 Практика и упражнения

Практические материалы для закрепления знаний и применения на практике.

## Что здесь есть

| Раздел | Описание |
|--------|----------|
| **Упражнения** | Практические задания по каждому модулю |
| **Чек-листы** | Готовые списки для проверки ваших действий |
| **Шаблоны** | Таблицы и формы для планирования |

## С чего начать

1. Пройдите хотя бы первые 3 модуля курса
2. Выполните упражнения по пройденным модулям
3. Используйте чек-листы при открытии счёта и совершении сделок
4. Заполните шаблоны для своего инвестиционного плана

> 💡 **Совет**: Практика — ключ к успеху. Не пропускайте упражнения!
