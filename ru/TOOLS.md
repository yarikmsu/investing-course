## 1. Брокеры

### Для резидентов США

| Брокер | Комиссии | Минимум | Особенности |
|--------|----------|---------|-------------|
| **Fidelity** | $0 | $0 | Отличная поддержка, fractional shares |
| **Charles Schwab** | $0 | $0 | Широкий выбор, банковские услуги |
| **Vanguard** | $0 | $0 | Создатели индексного инвестирования |
| **Robinhood** | $0 | $0 | Простой интерфейс (для начинающих) |
| **M1 Finance** | $0 | $100 | Автоматическая ребалансировка |

```
Рекомендация для новичков:
├── Fidelity — лучший баланс функций и простоты
├── Schwab — если нужны банковские услуги
└── Vanguard — для убеждённых "боглхедов"

⚠️ О Robinhood:
├── Простой интерфейс привлекает новичков
├── НО: геймификация может провоцировать частый трейдинг
├── Конфетти, уведомления — психологические приёмы
├── Для долгосрочного инвестирования лучше Fidelity/Schwab
└── Если используете — отключите уведомления!
```

## 4. Анализ портфелей

### Бэктестинг и моделирование

| Инструмент | Описание | |
|------------|----------|:-:|
| [testfol.io](https://testfol.io) | **ЛУЧШИЙ БЕСПЛАТНЫЙ** — бэктест портфелей без ограничений | 🆓 |
| [portfoliovisualizer.com](https://www.portfoliovisualizer.com) | Мощный бэктест, но история ограничена ~10 годами без подписки | 💰 |
| [portfoliocharts.com](https://portfoliocharts.com) | Визуализация разных стратегий | 🆓 |

### Как использовать Portfolio Visualizer

```
Основные функции:
├── Backtest Portfolio — тест на исторических данных
├── Asset Correlations — корреляция активов
├── Monte Carlo — моделирование будущего
├── Factor Analysis — факторный анализ
└── Asset Allocation — оптимальное распределение

Пример: сравнить VTI и VOO за 10 лет
1. Backtest Portfolio → Asset Allocation
2. Ввести тикеры и веса
3. Выбрать период
4. Analyze!
```

> ℹ️ С 2024 года часть функций Portfolio Visualizer стала платной.
> В бесплатном тарифе остаются базовые Backtest Portfolio и Monte Carlo,
> но история бэктеста ограничена ~10 годами и ~15 активами; расширенная
> история, факторный анализ и оптимизация — по подписке (~$30–55/мес).
> Для бесплатного бэктеста без ограничений используйте **testfol.io**.
