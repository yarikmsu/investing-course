## Урок 8.1: Подготовка к инвестированию

### Финансовый чек-лист

```
Перед началом инвестирования проверьте:

☐ Погашены высокопроцентные долги
   └── Кредитные карты, потребительские кредиты

☐ Создана подушка безопасности
   └── 3-6 месяцев расходов на savings account

☐ Есть стабильный доход
   └── Или другой источник для регулярных взносов

☐ Определены финансовые цели
   └── Пенсия, дом, образование детей

☐ Есть базовые знания (этот курс!)
   └── Понимание рисков и инструментов

☐ Готовность к долгосрочному инвестированию
   └── Минимум 5+ лет, идеально 15+
```

### Определение целей (SMART)

| Критерий | ❌ Плохая цель | ✅ Хорошая цель |
|----------|---------------|-----------------|
| **S**pecific (Конкретная) | "Хочу быть богатым" | "Накопить $500,000 к пенсии" |
| **M**easurable (Измеримая) | "Хочу больше денег" | "$1,000,000 к 60 годам" |
| **A**chievable (Достижимая) | "$10M за 5 лет с $1,000" | "$100k за 10 лет при $500/мес" |
| **R**elevant (Релевантная) | Оторвана от жизни | Связана с приоритетами |
| **T**ime-bound (Ограничена) | "Когда-нибудь" | "К 2045 году" |

### Расчёт необходимых инвестиций

```
Формула будущей стоимости:

FV = PMT × [((1 + r)^n - 1) / r]

Где:
FV — будущая стоимость
PMT — ежемесячный взнос
r — месячная доходность
n — количество месяцев

Пример:
Цель: $1,000,000 за 30 лет
Доходность: 7% годовых (0.58% в месяц)

$1,000,000 = PMT × [((1.0058)^360 - 1) / 0.0058]
$1,000,000 = PMT × 1,219.97
PMT = $820/месяц

Нужно инвестировать ~$820/месяц!
```

## Урок 8.3: Первая покупка акций

### ⚙️ Важные настройки ДО первой покупки

**Cost Basis Method (метод учёта стоимости):**

```
Методы:
├── FIFO (First In, First Out) — по умолчанию
│   └── Продаются сначала самые старые акции
├── LIFO (Last In, First Out)
│   └── Продаются сначала самые новые
├── SpecID (Specific Identification) — РЕКОМЕНДУЕТСЯ
│   └── Вы выбираете конкретные лоты при продаже
└── Average Cost — только для mutual funds

Почему SpecID лучше:
├── Можете выбрать лоты с максимальным убытком (TLH)
├── Можете выбрать лоты с минимальной прибылью
└── Максимальный контроль над налогами
```

> 💡 **Действие:** Зайдите в Settings → Tax Lot Method → выберите "Specific Identification"

**DRIP (Dividend Reinvestment Plan):**

```
Включить DRIP?

✅ Плюсы:
├── Автоматический сложный процент
├── Не нужно помнить о реинвестировании
└── Покупка дробных акций

⚠️ Минусы в Taxable Account:
├── Дивиденды облагаются налогом (даже реинвестированные!)
├── Множество мелких лотов усложняет учёт
├── Труднее делать Tax-Loss Harvesting
└── Много строк в 1099-B

Рекомендация:
├── В IRA/401(k): включить DRIP ✅
└── В Taxable: рассмотреть ручное реинвестирование
```

> 💡 **Действие:** Проверьте настройки DRIP в разделе Dividends → Reinvestment

### Пошаговая инструкция

```
1. Войдите в брокерский счёт

2. Найдите нужный актив
   ├── Введите тикер (например, VTI)
   └── Или название (Vanguard Total Stock)

3. Нажмите "Trade" или "Buy"

4. Заполните ордер:
   ├── Action: Buy
   ├── Quantity: количество акций ИЛИ сумма в долларах
   ├── Order Type: Limit (рекомендуется) — см. ниже
   ├── Time in Force: Day (ордер на день)
   └── Account: выберите нужный счёт

   💡 Order Type:
   ├── Limit: укажите цену на 0.1-0.2% выше текущей
   │   └── Защита от плохого исполнения
   ├── Market: только для VOO/VTI/SPY в середине дня
   │   └── Избегайте на открытии (9:30) и закрытии (16:00)
   └── Почему Limit лучше: при волатильности Market может
       исполниться по невыгодной цене

5. Проверьте детали
   ├── Общая стоимость
   ├── Комиссия (должна быть $0 для большинства)
   └── Предварительная цена

6. Подтвердите ордер
   └── "Review" → "Submit"

7. Проверьте исполнение
   ├── Для Market Order — мгновенно
   └── Для Limit Order — может занять время
```

### Пример покупки

```
Хотите инвестировать $5,000 в VTI

Допустим VTI торгуется по $250

Вариант 1: Покупка целых акций
├── $5,000 / $250 = 20 акций
├── Останется: $0
└── Подходит для большинства брокеров

Вариант 2: Fractional shares (дробные акции)
├── Fidelity, Schwab: можно купить на $5,000
├── Получите: 20.00 акций
└── Вся сумма инвестирована
```

### Что делать после покупки

```
✓ Проверьте позицию в портфеле
✓ Настройте DRIP (реинвестирование дивидендов)
✓ Запишите покупку для своих записей
✓ Установите напоминание для следующей покупки

✗ НЕ проверяйте цену каждый час
✗ НЕ паникуйте при небольших колебаниях
✗ НЕ продавайте при первом падении
```

## Урок 8.5: Мониторинг и корректировка

### Регулярные действия

```
Ежемесячно:
├── Регулярная инвестиция (автоматически)
└── Быстрая проверка что всё работает

Ежеквартально:
├── Проверка распределения активов
├── Оценка нужна ли ребалансировка
└── Налоговое планирование (для taxable счёта)

Ежегодно:
├── Полный обзор портфеля
├── Ребалансировка если нужно
├── Оценка прогресса к целям
├── Корректировка взносов
└── Налоговая отчётность
```

### Когда ребалансировать

```
Триггеры для ребалансировки:

1. Отклонение более 5% от целевого
   Пример: цель 70/30, стало 78/22 → ребалансировать

2. Прошёл год с последней ребалансировки

3. Значительное изменение жизненной ситуации
   ├── Смена работы
   ├── Брак/развод
   ├── Рождение ребёнка
   └── Приближение пенсии
```

### Отслеживание результатов

```
Что отслеживать:
├── Общая стоимость портфеля
├── Доходность (за год, с начала)
├── Сравнение с бенчмарком
├── Полученные дивиденды
└── Прогресс к целям

Инструменты:
├── Приложение брокера
├── Empower (бесплатно) — empower.com
├── Google Sheets / Excel
└── Специализированные приложения

⚠️ Не зацикливайтесь на краткосрочных результатах!
```

## Урок 8.7: Как читать налоговые формы

### Form 1099-DIV (Дивиденды)

```
Получаете в январе-феврале за прошлый год

Ключевые поля:
┌─────────────────────────────────────────────────┐
│ Box 1a: Total ordinary dividends                │
│         Общая сумма дивидендов                  │
│         → Облагается как обычный доход          │
├─────────────────────────────────────────────────┤
│ Box 1b: Qualified dividends                     │
│         Квалифицированные дивиденды             │
│         → Льготная ставка 0/15/20%              │
├─────────────────────────────────────────────────┤
│ Box 2a: Total capital gain distributions        │
│         Распределения прироста капитала         │
│         → Долгосрочная ставка                   │
├─────────────────────────────────────────────────┤
│ Box 4: Federal income tax withheld              │
│        Удержанный федеральный налог             │
│        → Обычно $0 для резидентов США           │
│        → Для нерезидентов: 15-30%               │
├─────────────────────────────────────────────────┤
│ Box 7: Foreign tax paid                         │
│        Иностранный налог (для VXUS и др.)       │
│        → Можно получить tax credit              │
└─────────────────────────────────────────────────┘

Пример:
Box 1a: $1,500 (общие дивиденды)
Box 1b: $1,200 (из них квалифицированные)
Box 7: $45 (иностранный налог)

Налог: $1,200 × 15% = $180, минус $45 credit = $135
Остальные $300 × ваша обычная ставка
```

### Form 1099-B (Продажи ценных бумаг)

```
Получаете если продавали акции/ETF

Ключевые поля:
┌─────────────────────────────────────────────────┐
│ Box 1d: Proceeds (выручка от продажи)           │
├─────────────────────────────────────────────────┤
│ Box 1e: Cost basis (стоимость покупки)          │
├─────────────────────────────────────────────────┤
│ Box 1g: Gain/loss (прибыль/убыток)              │
│         = Proceeds - Cost basis                 │
├─────────────────────────────────────────────────┤
│ Box 1c: Date acquired (дата покупки)            │
├─────────────────────────────────────────────────┤
│ Box 1b: Date sold (дата продажи)                │
│         Если держали >1 года = long-term        │
│         Если держали <1 года = short-term       │
└─────────────────────────────────────────────────┘

Пример:
Купили VTI за $5,000 в январе 2023
Продали за $6,500 в марте 2025 (>1 года)

Box 1d: $6,500 (proceeds)
Box 1e: $5,000 (cost basis)
Box 1g: $1,500 (long-term gain)

Налог: $1,500 × 15% = $225 (если доход $48,351-$533,400, 2025)
```

### Брокерский отчёт (Statement)

```
Что искать в ежемесячном/ежеквартальном отчёте:

Account Summary:
├── Beginning value — стоимость на начало периода
├── Ending value — стоимость на конец периода
├── Net change — изменение (прибыль/убыток)
└── Deposits/Withdrawals — пополнения/выводы

Holdings (Позиции):
├── Symbol — тикер актива
├── Quantity — количество акций
├── Price — текущая цена
├── Market value — рыночная стоимость
├── Cost basis — стоимость покупки
├── Unrealized G/L — нереализованная прибыль/убыток
└── % of portfolio — доля в портфеле

Income (Доходы):
├── Dividends — полученные дивиденды
├── Interest — проценты
└── Distributions — распределения

Activity (Активность):
├── Buys — покупки
├── Sells — продажи
├── Dividends received — полученные дивиденды
└── Dividend reinvestment — реинвестирование
```

### Пример расчёта налога

```
За год получили:
├── Qualified dividends: $2,000
├── Non-qualified dividends: $300
├── Long-term capital gain: $1,500
├── Short-term capital gain: $200
└── Foreign tax paid: $60

Доход: $80,000 (ставка 22% обычная, 15% льготная)

Расчёт:
Qualified dividends: $2,000 × 15% = $300
Non-qualified: $300 × 22% = $66
Long-term gain: $1,500 × 15% = $225
Short-term gain: $200 × 22% = $44

Итого до кредитов: $635
Минус Foreign Tax Credit: $60
Налог к уплате: $575
```

## Урок 8.9: Частые ошибки и как их избежать

### Топ-10 ошибок начинающих

```
1. Инвестирование без подушки безопасности
   ✗ Придётся продавать в плохой момент
   ✓ Сначала 3-6 месяцев расходов в наличных

2. Попытка угадать рынок
   ✗ "Подожду пока упадёт"
   ✓ Инвестируйте регулярно, время в рынке важнее

3. Отсутствие диверсификации
   ✗ Всё в одной акции или секторе
   ✓ Широкие индексные ETF

4. Паника при падениях
   ✗ Продажа на дне
   ✓ Следуйте плану, это возможность докупить

5. Погоня за доходностью
   ✗ "Эта акция выросла на 500%!"
   ✓ Прошлая доходность не гарантирует будущую

6. Слишком частые сделки
   ✗ Постоянные покупки/продажи
   ✓ Комиссии и налоги съедают прибыль

7. Игнорирование комиссий
   ✗ Дорогие активно управляемые фонды
   ✓ Expense ratio имеет огромное значение

8. Отсутствие плана
   ✗ Эмоциональные решения
   ✓ Письменный план и дисциплина

9. Попытка обыграть рынок
   ✗ Stock picking без опыта
   ✓ Индексное инвестирование

10. Откладывание начала
    ✗ "Начну когда будет больше денег"
    ✓ Время — главный фактор, начните сейчас!
```

## Финальный тест курса

<details>
<summary><b>Вопрос 1:</b> Какие три условия должны быть выполнены перед началом инвестирования?</summary>

**Ответ:**
1. Погашены высокопроцентные долги (кредитные карты)
2. Создана подушка безопасности (3-6 месяцев расходов)
3. Определены финансовые цели и горизонт инвестирования

</details>

<details>
<summary><b>Вопрос 2:</b> Сколько нужно инвестировать ежемесячно, чтобы накопить $1,000,000 за 30 лет при 7% годовых?</summary>

**Ответ:** Примерно $820/месяц. Формула: $1,000,000 ÷ 1219.97 (множитель для 30 лет при 7%) = ~$820.

</details>

<details>
<summary><b>Вопрос 3:</b> Какой простой портфель подходит для начинающего 30-летнего инвестора?</summary>

**Ответ:**
- VTI (Акции США): 70-80%
- VXUS (Международные акции): 10-20%
- BND (Облигации): 10-20%

Или просто: 90% VTI + 10% BND.

</details>

<details>
<summary><b>Вопрос 4:</b> Назовите 3 самые частые ошибки начинающих инвесторов.</summary>

**Ответ:** (любые 3 из списка)
1. Инвестирование без подушки безопасности
2. Попытка угадать рынок (market timing)
3. Отсутствие диверсификации
4. Паника при падениях
5. Погоня за доходностью
6. Слишком частые сделки
7. Отсутствие плана
8. Откладывание начала инвестирования

</details>

<details>
<summary><b>Вопрос 5:</b> Какой главный принцип философии Bogleheads?</summary>

**Ответ:** Пассивное индексное инвестирование с низкими комиссиями. "Купи рынок и держи". Время в рынке важнее тайминга рынка. 2-4 ETF достаточно для полноценного портфеля.

</details>

<details>
<summary><b>Вопрос 6:</b> Что нужно сделать сразу после первой покупки ETF?</summary>

**Ответ:**
1. Проверить позицию в портфеле
2. Настроить DRIP (реинвестирование дивидендов)
3. Настроить автоматические регулярные покупки
4. НЕ проверять цену каждый час и НЕ паниковать при колебаниях

</details>

<details>
<summary><b>Вопрос 7:</b> Какой размер подушки безопасности рекомендуется перед началом инвестирования?</summary>

**Ответ:** 3-6 месяцев расходов на savings account. Для самозанятых или при нестабильном доходе — до 12 месяцев.

</details>

<details>
<summary><b>Вопрос 8:</b> В чём разница между NYSE и NASDAQ?</summary>

**Ответ:**
- NYSE — старейшая биржа (1792), физическая торговая площадка, крупнейшие традиционные компании
- NASDAQ — электронная биржа (1971), фокус на технологических компаниях
- Обе регулируются SEC и одинаково надёжны

</details>

<details>
<summary><b>Вопрос 9:</b> Что такое S&P 500?</summary>

**Ответ:** Индекс 500 крупнейших публичных компаний США по капитализации. Покрывает ~80% рынка США. Главный бенчмарк для оценки результатов инвестирования.

</details>

<details>
<summary><b>Вопрос 10:</b> В чём разница между акцией и облигацией?</summary>

**Ответ:**
- Акция = доля владения в компании. Высокий риск, высокая потенциальная доходность.
- Облигация = долг. Вы даёте в долг и получаете проценты. Ниже риск, ниже доходность.

</details>

<details>
<summary><b>Вопрос 11:</b> Что такое ETF и почему он популярен?</summary>

**Ответ:** Exchange-Traded Fund — фонд, торгуемый на бирже как акция. Популярен из-за: низких комиссий (от 0.03%), мгновенной диверсификации, ликвидности, налоговой эффективности.

</details>

<details>
<summary><b>Вопрос 12:</b> Что означает Expense Ratio 0.03%?</summary>

**Ответ:** Годовая комиссия фонда. 0.03% = $3 в год на каждые $10,000 вложений. Автоматически вычитается из стоимости фонда.

</details>

<details>
<summary><b>Вопрос 13:</b> В чём разница между Traditional IRA и Roth IRA?</summary>

**Ответ:**
- Traditional IRA: взносы уменьшают налоги сейчас, платите налог при выводе
- Roth IRA: взносы из дохода после налогов, вывод без налога
- Roth лучше если ожидаете более высокие налоги в будущем

</details>

<details>
<summary><b>Вопрос 14:</b> Какой лимит взноса в IRA на 2025 год?</summary>

**Ответ:** $7,000 в год ($8,000 для возраста 50+). Лимит общий для Traditional и Roth IRA.

</details>

<details>
<summary><b>Вопрос 15:</b> В чём преимущество 401(k) перед IRA?</summary>

**Ответ:**
- Более высокий лимит: $23,500 в год (vs $7,000 для IRA)
- Employer matching — бесплатные деньги от работодателя
- Автоматические отчисления из зарплаты

</details>

<details>
<summary><b>Вопрос 16:</b> Какая налоговая ставка на квалифицированные дивиденды?</summary>

**Ответ:** 0%, 15% или 20% в зависимости от дохода. Для большинства — 15%. Это ниже, чем обычная ставка подоходного налога.

</details>

<details>
<summary><b>Вопрос 17:</b> Что такое Dollar-Cost Averaging (DCA)?</summary>

**Ответ:** Регулярное инвестирование фиксированной суммы независимо от цены рынка. Снижает риск покупки на пике. Пример: $500 каждый месяц.

</details>

<details>
<summary><b>Вопрос 18:</b> Почему пассивное инвестирование обычно лучше активного?</summary>

**Ответ:** ~90% активных фондов проигрывают индексу за 15+ лет. Причины: высокие комиссии, торговые издержки, налоги, человеческие ошибки.

</details>

<details>
<summary><b>Вопрос 19:</b> В чём разница между VTI и VOO?</summary>

**Ответ:**
- VTI — весь рынок США (~4,000 компаний), включая small/mid-cap
- VOO — только S&P 500 (500 крупнейших)
- Доходность очень похожа, VTI чуть больше диверсификации

</details>

<details>
<summary><b>Вопрос 20:</b> Когда нужно ребалансировать портфель?</summary>

**Ответ:**
1. При отклонении более 5% от целевого распределения
2. Раз в год по календарю
3. При значительных изменениях жизненной ситуации

</details>

<details>
<summary><b>Вопрос 21:</b> Что такое риск последовательности доходности (sequence of returns risk)?</summary>

**Ответ:** Риск получить низкую доходность в первые годы после выхода на пенсию. Падение рынка при активном выводе средств может истощить портфель быстрее.

</details>

<details>
<summary><b>Вопрос 22:</b> Что такое FOMO и почему это опасно?</summary>

**Ответ:** Fear Of Missing Out — страх упустить прибыль. Опасно, потому что заставляет покупать на пике после роста, игнорируя риски.

</details>

<details>
<summary><b>Вопрос 23:</b> Как правило 72 помогает инвестору?</summary>

**Ответ:** 72 ÷ доходность = лет до удвоения капитала. Пример: 72 ÷ 7% = ~10 лет. Помогает быстро оценить рост инвестиций.

</details>

<details>
<summary><b>Вопрос 24:</b> Что такое форма W-8BEN и кому она нужна?</summary>

**Ответ:** Форма для нерезидентов США для снижения налога на дивиденды (обычно с 30% до 10-15% по налоговому соглашению). Действует 3 года.

</details>

<details>
<summary><b>Вопрос 25:</b> Что такое DRIP?</summary>

**Ответ:** Dividend Reinvestment Plan — автоматическое реинвестирование дивидендов в покупку дополнительных акций. Увеличивает эффект сложного процента.

</details>

<details>
<summary><b>Вопрос 26:</b> Какой максимальный убыток можно списать с налогов ежегодно?</summary>

**Ответ:** $3,000 чистых убытков от инвестиций можно списать против обычного дохода. Остаток переносится на следующие годы.

</details>

<details>
<summary><b>Вопрос 27:</b> Что такое wash sale rule?</summary>

**Ответ:** Правило, запрещающее списывать убыток, если вы купили тот же или существенно идентичный актив в течение 30 дней до или после продажи.

</details>

<details>
<summary><b>Вопрос 28:</b> Сколько ETF достаточно для диверсифицированного портфеля?</summary>

**Ответ:** 2-4 ETF. Например: VTI (акции США) + VXUS (международные) + BND (облигации). Или просто VT (весь мир).

</details>

<details>
<summary><b>Вопрос 29:</b> Что такое 4% правило?</summary>

**Ответ:** Правило безопасного вывода: можно выводить 4% портфеля ежегодно с высокой вероятностью не исчерпать средства за 30 лет. $1M × 4% = $40,000/год.

</details>

<details>
<summary><b>Вопрос 30:</b> Почему "время в рынке" важнее "тайминга рынка"?</summary>

**Ответ:** Пропуск даже нескольких лучших дней рынка резко снижает доходность. Невозможно предсказать эти дни. Постоянное пребывание в рынке статистически выгоднее.

</details>

**Результаты:**
- 25-30 правильных: Отлично! Вы готовы начать инвестировать!
- 18-24 правильных: Хорошо, но перечитайте слабые темы
- 10-17 правильных: Пройдите курс ещё раз
- 0-9 правильных: Начните с модуля 0
