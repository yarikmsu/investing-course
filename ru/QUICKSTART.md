# Быстрый старт: Первые $500 за 7 дней

> 🚀 **Цель:** За одну неделю превратиться из "думаю об инвестициях" в "у меня есть инвестиции".

---

## Прежде чем начать

### Убедитесь, что вы готовы

```
□ Нет долгов по кредитным картам
□ Есть подушка безопасности (хотя бы 1-2 месяца)
□ Деньги не понадобятся в ближайшие 5 лет
□ Готовы к тому, что инвестиции могут временно упасть
```

Если не уверены — сначала пройдите [Модуль 0](/investing-course/ru/module-00-preparation/).

## День 2-3: Открытие счёта

### Какие документы понадобятся

**Для резидентов США:**
```
├── Social Security Number (SSN)
├── Водительские права или паспорт
├── Адрес проживания
└── Информация о работодателе
```

**Для нерезидентов:**
```
├── Загранпаспорт
├── Подтверждение адреса (utility bill, выписка из банка)
├── Налоговый идентификатор вашей страны
└── Иногда: подтверждение источника средств
```

### Какой тип счёта выбрать?

```
Вы резидент США?
│
├── ДА → Есть ли у вас 401(k) с match?
│        │
│        ├── ДА → Сначала 401(k) до match, потом Roth IRA
│        └── НЕТ → Roth IRA (если подходите по доходу)
│                  или Taxable Account
│
└── НЕТ → Taxable Account (обычный брокерский счёт)
          + Заполните форму W-8BEN!
```

### Пошаговый процесс

```
Шаг 1: Заполните личные данные
├── Имя, адрес, дата рождения
├── Гражданство и резидентство
└── Контактные данные

Шаг 2: Ответьте на вопросы
├── Инвестиционный опыт (можно "Limited")
├── Финансовое положение
├── Инвестиционные цели
└── Толерантность к риску

Шаг 3: Подтвердите личность
├── Загрузите документы
├── Дождитесь проверки (1-3 дня)
└── Получите подтверждение по email

⚠️ ВАЖНО для нерезидентов:
Заполните форму W-8BEN сразу после открытия счёта!
Это снизит налог на дивиденды с 30% до 10-15%.
```

### Частые ошибки при регистрации

```
❌ Опечатки в имени → проблемы с документами
❌ Неправильный адрес → не придут важные письма
❌ Пропуск W-8BEN → переплата налогов
❌ Слишком агрессивный профиль → могут отказать в опционах
```

## День 4: Пополнение счёта

### Способы пополнения

**Для резидентов США:**
```
ACH Transfer (рекомендуется):
├── Бесплатно
├── 2-3 рабочих дня
└── Настройте в приложении банка или брокера

Wire Transfer:
├── Быстро (тот же день)
├── Может быть платно ($15-25)
└── Для срочных случаев
```

**Для нерезидентов:**
```
Международный Wire Transfer:
├── SWIFT перевод из вашего банка
├── Комиссия банка (~$20-50)
├── Конвертация в USD
├── 1-3 рабочих дня
└── Сохраните все квитанции!
```

### Сколько переводить?

```
Минимум для старта: $100-500
├── Достаточно для покупки ETF
├── Психологически комфортно потерять временно
└── Можно докупать потом

Рекомендуемый первый перевод: $500-1,000
├── Больше гибкости
├── Меньше относительных комиссий
└── Хороший старт

Не переводите сразу всё:
├── Оставьте подушку безопасности!
├── Лучше регулярные небольшие переводы
└── DCA (усреднение) работает лучше
```

## День 5: Первая покупка

### Что купить?

**Для абсолютного новичка — один ETF:**

```
VTI — Vanguard Total Stock Market ETF

Почему VTI:
├── Весь рынок США (~4,000 компаний)
├── Максимальная диверсификация
├── Expense ratio: 0.03% ($3 на $10,000 в год)
├── Один из крупнейших ETF в мире
└── Проще некуда
```

**Альтернативы:**
```
VOO — Vanguard S&P 500 (500 крупнейших компаний)
SPY — SPDR S&P 500 (то же самое, чуть дороже)
ITOT — iShares Total Stock Market (аналог VTI)
```

### Как купить — пошаговая инструкция

```
Шаг 1: Войдите в приложение/сайт брокера

Шаг 2: Найдите ETF
├── Введите в поиске: VTI
├── Убедитесь: "Vanguard Total Stock Market ETF"
└── Проверьте текущую цену

Шаг 3: Нажмите "Trade" или "Buy"

Шаг 4: Заполните ордер
├── Action: Buy
├── Количество: введите сумму в долларах
│   (например: $500)
├── Order Type: Market (рыночный)
├── Duration: Day
└── Account: ваш счёт

Шаг 5: Проверьте детали
├── Примерная цена
├── Количество акций
├── Комиссия ($0)
└── Итого

Шаг 6: Подтвердите
├── Нажмите "Submit" или "Place Order"
└── Готово! 🎉

Шаг 7: Проверьте
├── Перейдите в раздел "Positions" или "Portfolio"
├── VTI должен появиться в списке
└── Сохраните скриншот для истории!
```

### Рыночный vs Лимитный ордер

```
Market Order (рыночный):
├── Исполняется сразу
├── По текущей рыночной цене
├── Для ETF — почти всегда подходит
└── Рекомендуется для новичков

Limit Order (лимитный):
├── Исполняется по вашей цене или лучше
├── Может не исполниться
├── Для продвинутых или крупных сумм
└── Полезен при волатильности
```

## День 6-7: Настройка автоматизации

### Автоматические инвестиции

```
Зачем:
├── Убирает эмоции из процесса
├── Не нужно помнить
├── Работает концепция DCA
└── "Заплати сначала себе"

Как настроить:
1. В приложении брокера найдите "Automatic Investments"
2. Выберите ETF (VTI)
3. Укажите сумму ($100-500/месяц)
4. Выберите дату (например, 1-е число)
5. Привяжите источник денег (банковский счёт)
6. Активируйте
```

### DRIP — реинвестирование дивидендов

```
Что это:
├── Дивиденды автоматически покупают новые акции
├── Ускоряет сложный процент
├── Не нужно делать ничего вручную
└── Обычно включено по умолчанию

Как проверить:
1. Settings → Dividends
2. Убедитесь: "Reinvest dividends" = ON
```

### Что дальше?

```
Неделя 2-4:
├── Пройдите остальные модули курса
├── Не трогайте инвестиции
├── Продолжайте автоматические покупки

Через месяц:
├── Проверьте, что автоматика работает
├── Посмотрите на баланс (но не часто!)
└── Увеличьте взносы если можете

Через год:
├── Оцените прогресс
├── Подумайте о диверсификации (добавить международные?)
└── Ребалансировка если нужно
```

## Частые вопросы о первой покупке

**Q: А если рынок завтра упадёт?**
```
A: Это нормально и даже хорошо — следующие покупки
   будут по более низкой цене. Вы инвестируете на
   10+ лет, краткосрочные колебания не имеют значения.
```

**Q: $500 — это слишком мало?**
```
A: Нет! Важно начать. $500 в месяц под 10% годовых
   за 30 лет превратятся в ~$1,000,000.

   ⚠️ Это не гарантия. 10% — долгосрочная номинальная
   доходность рынка США в прошлом; реальная доходность
   после инфляции ниже (~6–7%), а прогнозы на ближайшие
   10 лет — порядка 4–6% реальных. Считайте это ориентиром,
   а не обещанием.
```

**Q: Почему именно VTI?**
```
A: Максимальная простота + диверсификация + низкие
   комиссии. Для первой покупки — идеально.
   Усложнить всегда можно потом.
```

**Q: Когда добавить другие ETF?**
```
A: Когда пройдёте весь курс и поймёте, зачем.
   Многие инвесторы всю жизнь держат только VTI
   и отлично себя чувствуют.
```
