# Модуль 0: Готовы ли вы к инвестированию?

> ⚠️ **ВАЖНО: Это образовательный материал, а не финансовый совет.**
>
> **Инвестирование связано с рисками. Вы можете потерять часть или ВСЕ вложенные деньги.**
>
> - S&P 500 падал на 57% (2008-2009), 34% (2020), 25% (2022)
> - Прошлые результаты НЕ гарантируют будущих
> - Перед инвестированием проконсультируйтесь с лицензированным финансовым специалистом (CFA/CFP)

> **Пройдите этот модуль перед началом инвестирования.** Он поможет убедиться, что вы готовы финансово и психологически.

---

## 📋 Что вы узнаете

| | |
|---|---|
| **Уровень** | 🟢 Новичок |
| **Время изучения** | ~20 минут |
| **Требуемые знания** | Нет (это первый модуль!) |

После прохождения этого модуля вы сможете:
- ✅ Оценить своё финансовое здоровье
- ✅ Рассчитать необходимую подушку безопасности
- ✅ Составить или проверить бюджет
- ✅ Понять, когда НЕ стоит инвестировать
- ✅ Пройти тест готовности к инвестированию

## Урок 0.1: Финансовое здоровье

### Где вы сейчас?

Прежде чем инвестировать, ответьте честно на эти вопросы:

```
□ Я знаю свой ежемесячный доход
□ Я знаю свои ежемесячные расходы
□ У меня нет долгов по кредитным картам
□ У меня есть сбережения на непредвиденные расходы
□ Мне не понадобятся эти деньги в ближайшие 3-5 лет
```

**Если вы не можете поставить галочку хотя бы у 3 пунктов — сначала решите эти проблемы.**

### Правило 50/30/20

Простая система распределения дохода:

```
Ваш доход после налогов
         │
         ▼
┌─────────────────────────────────────────┐
│                                         │
│  50% — НЕОБХОДИМОЕ                      │
│  ├── Жильё (аренда/ипотека)             │
│  ├── Еда                                │
│  ├── Транспорт                          │
│  ├── Коммунальные услуги                │
│  └── Страховки                          │
│                                         │
│  30% — ЖЕЛАЕМОЕ                         │
│  ├── Развлечения                        │
│  ├── Рестораны                          │
│  ├── Хобби                              │
│  └── Подписки                           │
│                                         │
│  20% — СБЕРЕЖЕНИЯ И ИНВЕСТИЦИИ          │
│  ├── Подушка безопасности               │
│  ├── Пенсионные накопления              │
│  └── Инвестиции                         │
│                                         │
└─────────────────────────────────────────┘
```

Заполните таблицу:

|-----------|------------|-------------|-------|
| Доход после налогов | $_____ | 100% | — |

| Сбережения/инвестиции | $_____ | ___% | ≥20% |

## Урок 0.2: Долги — враг инвестора

### Хорошие и плохие долги

| Категория | Тип долга | Ставка | Действие |
|-----------|-----------|--------|----------|
| ⚠️ **Плохие** | Кредитные карты | 15-25% | Погасить сначала! |
| ⚠️ **Плохие** | Потребительские кредиты | 10-20% | Погасить сначала! |
| ⚠️ **Плохие** | Микрозаймы | 100%+ | Погасить немедленно! |
| ⚠️ **Плохие** | Автокредит (дорогая машина) | 8-15% | Погасить или продать |
| 🟡 **Нейтральные** | Студенческий кредит | 5-8% | Платить по графику |
| 🟡 **Нейтральные** | Автокредит (недорогая машина) | 5-10% | Платить по графику |
| ✅ **Допустимые** | Ипотека | 3-7% | Можно инвестировать параллельно |
| ✅ **Допустимые** | Бизнес-кредит | 5-10% | Если окупается |

### Математика: Долг vs Инвестиции

```
Ситуация:
├── Долг по кредитке: $5,000 под 20% годовых
├── Свободные деньги: $5,000
└── Ожидаемая доходность инвестиций: 10%

Вариант А: Инвестировать
├── Через год: $5,500 в инвестициях
├── Долг вырос до: $6,000
└── Итого: -$500

Вариант Б: Погасить долг
├── Долг: $0
├── Сэкономлено на процентах: $1,000
└── Итого: +$1,000

Вывод: Погашение долга под 20% = гарантированная
       доходность 20%. Инвестиции исторически дают
       ~10% в среднем (номинально, до инфляции) и
       НЕ гарантированно.
```

> ℹ️ В этом и суть контраста: погашение долга — это **точный**, гарантированный «доход» (вы экономите ровно те проценты, которые иначе заплатили бы), тогда как доходность акций **неопределённа** и меняется год от года. Поэтому высокопроцентный долг разумно гасить в первую очередь.

### Стратегии погашения долгов

**Метод "Снежный ком" (Snowball):**
```
1. Погашайте минимумы по всем долгам
2. Все свободные деньги — на САМЫЙ МАЛЕНЬКИЙ долг
3. Когда он погашен — переходите к следующему
4. Психологическая победа мотивирует продолжать
```

**Метод "Лавина" (Avalanche):**
```
1. Погашайте минимумы по всем долгам
2. Все свободные деньги — на долг с САМОЙ ВЫСОКОЙ ставкой
3. Математически оптимальный метод
4. Экономите больше на процентах
```

### Когда можно инвестировать с долгами?

```
✓ МОЖНО инвестировать если:
├── Долг — только ипотека под низкий %
├── Есть match от работодателя в 401(k)
│   (бесплатные деньги — не упускайте!)
└── Ставка по долгу < 6-7%

✗ НЕЛЬЗЯ инвестировать если:
├── Есть долг по кредитным картам
├── Ставка по долгу > 10%
└── Нет подушки безопасности
```

## Урок 0.3: Подушка безопасности

### Зачем нужна подушка?

```
Без подушки безопасности:
├── Потеряли работу
├── Нужны деньги срочно
├── Приходится продавать инвестиции
├── Рынок как раз упал на 30%
└── Потеряли $3,000 из $10,000 😢

С подушкой безопасности:
├── Потеряли работу
├── Живёте на подушку 3-6 месяцев
├── Инвестиции не трогаете
├── Рынок восстановился
└── Всё в порядке 😊
```

### Сколько нужно?

```
МИНИМУМ: 3 месяца расходов
├── Для стабильной работы
├── Для семьи с двумя доходами
└── Если легко найти новую работу

ОПТИМУМ: 6 месяцев расходов
├── Для большинства людей
├── Для семьи с одним доходом
└── Стандартная рекомендация

МАКСИМУМ: 12 месяцев расходов
├── Для фрилансеров
├── Для нестабильного дохода
├── Для тех, кто спит спокойнее
└── Для предпенсионного возраста
```

### Где хранить подушку?

```
✓ ПОДХОДИТ:
├── High-Yield Savings Account (HYSA) — ~3.5-4.3% годовых (проверяйте актуальные ставки)
├── Money Market Account
├── Короткие Treasury Bills
└── Накопительный счёт в надёжном банке

✗ НЕ ПОДХОДИТ:
├── Инвестиции в акции (волатильность!)
├── Криптовалюта (ещё хуже!)
├── Наличные дома (инфляция + риск)
└── Обычный текущий счёт (0% годовых)
```

### Как накопить подушку?

```
Шаг 1: Рассчитайте цель
├── Ежемесячные расходы: $3,000
├── Цель (6 месяцев): $18,000
└── Уже есть: $2,000 → Нужно: $16,000

Шаг 2: Автоматизируйте
├── Настройте автоперевод в день зарплаты
├── Начните с $200-500 в месяц
└── Увеличивайте по возможности

Шаг 3: Ускорьте
├── Бонусы → в подушку
├── Налоговый возврат → в подушку
├── Подработка → в подушку
└── Цель: 12-18 месяцев до полной подушки
```

## Урок 0.4: Тест готовности к инвестированию

### Пройдите тест

Отвечайте честно. За каждый ответ "Да" — 1 балл.

```
ФИНАНСОВАЯ ГОТОВНОСТЬ:

1. У меня нет долгов по кредитным картам
   □ Да  □ Нет

2. У меня есть подушка безопасности (минимум 3 месяца расходов)
   □ Да  □ Нет

3. Я знаю свои ежемесячные доходы и расходы
   □ Да  □ Нет

4. У меня есть стабильный доход
   □ Да  □ Нет

5. Мне не понадобятся эти деньги в ближайшие 5 лет
   □ Да  □ Нет

ПСИХОЛОГИЧЕСКАЯ ГОТОВНОСТЬ:

6. Я понимаю, что инвестиции могут временно упасть на 30-50%
   □ Да  □ Нет

7. Я готов(а) не трогать инвестиции минимум 5-10 лет
   □ Да  □ Нет

8. Я не буду паниковать и продавать при падении рынка
   □ Да  □ Нет

ЗНАНИЯ:

9. Я понимаю разницу между акциями, облигациями и ETF
   □ Да  □ Нет

10. Я понимаю, что никто не может гарантировать доходность
    □ Да  □ Нет
```

### Результаты теста

```
9-10 баллов: ✅ ВЫ ГОТОВЫ!
Можете начинать инвестировать.
Переходите к "Быстрому старту".

7-8 баллов: ⚠️ ПОЧТИ ГОТОВЫ
Пройдите курс полностью перед началом.
Обратите внимание на пункты, где ответили "Нет".

5-6 баллов: ⏸️ ПОДОЖДИТЕ
Сначала решите финансовые проблемы.
Создайте подушку безопасности.
Погасите высокопроцентные долги.

0-4 балла: 🛑 НЕ ГОТОВЫ
Инвестирование сейчас принесёт больше вреда.
Сфокусируйтесь на финансовом фундаменте.
Вернитесь через 6-12 месяцев.
```

## Что делать, если не готовы?

### План на 6 месяцев

```
Месяц 1-2: Разберитесь с бюджетом
├── Отслеживайте все расходы
├── Найдите, где сократить
└── Определите сумму для сбережений

Месяц 2-4: Погасите плохие долги
├── Составьте список всех долгов
├── Выберите стратегию (снежный ком / лавина)
└── Направляйте все свободные деньги на погашение

Месяц 3-6: Создайте подушку
├── Откройте HYSA
├── Настройте автоматические переводы
└── Накопите минимум 3 месяца расходов

После этого: Вернитесь к инвестированию!
```

### Полезные ресурсы

```
Бюджетирование:
├── YNAB (You Need A Budget) — платный
├── Monarch — платный
├── Empower — бесплатный
└── Простая таблица в Excel/Google Sheets — бесплатно

Погашение долгов:
├── unbury.me — калькулятор погашения
└── Метод конвертов для контроля расходов

Подушка безопасности:
├── HYSA: Marcus, Ally, Discover
└── Автоматические переводы в любом банке
```

## Практическое задание

1. **Заполните бюджетную таблицу** из урока 0.1
2. **Составьте список всех долгов** с суммами и ставками
3. **Рассчитайте размер подушки** (6 × ежемесячные расходы)
4. **Пройдите тест готовности** честно
5. **Определите следующий шаг:**
   - Готовы → переходите к Быстрому старту
   - Не готовы → составьте план на 6 месяцев
