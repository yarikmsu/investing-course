# 🌍 Для разных аудиторий

Специальные разделы для инвесторов с разным статусом и опытом.

## Выберите свой раздел

| Раздел | Для кого |
|--------|----------|
| **Нерезиденты США** | Инвесторы, живущие за пределами США (кроме России) |
| **Россияне** | Инвесторы — резиденты России |
| **Продвинутые стратегии** | Опытные инвесторы, готовые к сложным темам |

## Как определить свой статус

<div id="ic-wizard-root"></div>

<details>
<summary markdown="span">Текстовая версия (дерево решений)</summary>

```
Вы живёте в США?
├── Да → Основной курс (модули 1-8)
└── Нет
    ├── Вы резидент России?
    │   ├── Да → Раздел «Россияне»
    │   └── Нет → Раздел «Нерезиденты США»
    └── Хотите углубиться? → «Продвинутые стратегии»
```

</details>

> ⚠️ **Важно**: Основной курс написан для резидентов США. Если вы нерезидент — обязательно изучите соответствующий раздел.
