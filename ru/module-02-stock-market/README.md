## Урок 2.1: Структура американского фондового рынка

### Основные биржи

#### NYSE (New York Stock Exchange)
- Крупнейшая биржа в мире
- Основана в 1792 году
- Расположена на Уолл-стрит в Нью-Йорке
- Торгуются крупнейшие компании: Berkshire Hathaway, Johnson & Johnson, Walmart
- Символ: белый фасад с колоннами

#### NASDAQ
- Первая электронная биржа
- Основана в 1971 году
- Фокус на технологических компаниях
- Apple, Microsoft, Amazon, Google, Meta, Tesla
- Полностью электронные торги

#### Другие площадки
- **NYSE American** (бывшая AMEX) — малые и средние компании
- **OTC Markets** — внебиржевой рынок
- **Dark Pools** — приватные площадки для крупных сделок

## Урок 2.2: Время работы рынка

### Торговые сессии (по времени Восточного побережья США)

| Сессия | Время (ET) | Время (МСК) | Описание |
|--------|-----------|-------------|----------|
| Pre-market | 4:00 - 9:30 | 11:00 - 16:30 | Пониженная ликвидность |
| Regular | 9:30 - 16:00 | 16:30 - 23:00 | Основная торговая сессия |
| After-hours | 16:00 - 20:00 | 23:00 - 03:00 | Пониженная ликвидность |

### Выходные дни (биржа закрыта)

- New Year's Day (1 января)
- Martin Luther King Jr. Day (3-й понедельник января)
- Presidents' Day (3-й понедельник февраля)
- Good Friday (пятница перед Пасхой)
- Memorial Day (последний понедельник мая)
- Juneteenth (19 июня)
- Independence Day (4 июля)
- Labor Day (1-й понедельник сентября)
- Thanksgiving Day (4-й четверг ноября)
- Christmas Day (25 декабря)

### Важные моменты

```
⚠️ Учитывайте разницу во времени!

Для Москвы:
- Открытие рынка: 16:30 МСК
- Закрытие рынка: 23:00 МСК

Зимнее/летнее время может сдвигать расписание на 1 час.
```

## Урок 2.3: Основные индексы

### S&P 500

Индекс 500 крупнейших американских компаний.

```
Характеристики:
├── 500 компаний
├── ~80% капитализации всего рынка США
├── Взвешен по капитализации
└── Главный бенчмарк для инвесторов

Топ компании (примерные веса):
├── NVIDIA       ~8%
├── Apple        ~7%
├── Alphabet     ~6%
├── Microsoft    ~5%
└── Amazon       ~4%
```

### Dow Jones Industrial Average (DJIA)

Старейший индекс США, 30 компаний.

```
Характеристики:
├── 30 "голубых фишек"
├── Взвешен по цене акции
├── Включает только крупнейшие компании
└── Менее репрезентативен, чем S&P 500

Примеры компаний:
├── Apple
├── Boeing
├── Coca-Cola
├── Goldman Sachs
└── McDonald's
```

### NASDAQ Composite

Все компании, торгуемые на NASDAQ.

```
Характеристики:
├── ~3,000+ компаний
├── Фокус на технологиях
├── Высокая волатильность
└── Быстрый рост в хорошие времена

NASDAQ-100:
├── 100 крупнейших нефинансовых компаний
└── Основа ETF QQQ
```

### Сравнение индексов

| Индекс | Количество | Тип взвешивания | Фокус |
|--------|------------|-----------------|-------|
| S&P 500 | 500 | По капитализации | Широкий рынок |
| Dow Jones | 30 | По цене | Голубые фишки |
| NASDAQ | 3000+ | По капитализации | Технологии |
| Russell 2000 | 2000 | По капитализации | Малые компании |

## Урок 2.4: Как читать биржевую информацию

### Тикер (Ticker Symbol)

Уникальный буквенный код компании:

```
AAPL  — Apple
MSFT  — Microsoft
GOOGL — Alphabet (Google)
AMZN  — Amazon
TSLA  — Tesla
META  — Meta (Facebook)
```

### Биржевая котировка

```
AAPL (Apple Inc.)
├── Last: $175.50        ← Последняя цена сделки
├── Bid: $175.48         ← Цена покупки
├── Ask: $175.52         ← Цена продажи
├── Spread: $0.04        ← Разница bid/ask
├── Volume: 45.2M        ← Объём торгов (акций)
├── Avg Volume: 52.1M    ← Средний объём
├── Day Range: $173.20 - $176.30  ← Диапазон дня
├── 52W Range: $124.17 - $198.23  ← Диапазон года
├── Market Cap: $2.75T   ← Капитализация
├── P/E: 28.5            ← Цена/Прибыль
└── Div Yield: 0.55%     ← Дивидендная доходность
```

### Типы ордеров

#### Market Order (Рыночный ордер)
Покупка/продажа по текущей рыночной цене.

```
+ Мгновенное исполнение
- Цена может отличаться от ожидаемой
```

#### Limit Order (Лимитный ордер)
Покупка/продажа по указанной цене или лучше.

```
+ Контроль над ценой
- Может не исполниться
```

#### Stop Order (Стоп-ордер)
Становится рыночным при достижении указанной цены.

```
Используется для:
├── Ограничения убытков (Stop-Loss)
└── Фиксации прибыли (Take-Profit)
```

> ⚠️ Stop-Loss и Take-Profit — это инструменты выбора момента (тайминга), они противоречат долгосрочной стратегии buy-and-hold. Стоп-лосс может «выбить» вас из позиции на временной просадке как раз перед восстановлением рынка. Пассивному индексному инвестору они не нужны.

#### Stop-Limit Order
Комбинация стоп и лимит ордера.

> 💡 **Современные реалии (2026):** у крупных американских брокеров (Fidelity, Schwab, Vanguard) торговля акциями и ETF, котирующимися в США, идёт **за $0 комиссии** — это стандарт с 2019 года (касается онлайн-ордеров; опционы и некоторые иностранные/OTC-сделки могут иметь сборы). Сделки рассчитываются по правилу **T+1** — на следующий торговый день (введено 28 мая 2024 года). Для пассивного инвестора это означает: покупка VOO/VTI бесплатна, а деньги от продажи становятся доступны на следующий рабочий день.

## Урок 2.5: Как формируется цена акции

### Спрос и предложение

```
         Покупатели          Продавцы
              │                   │
              ▼                   ▼
         ┌────────┐         ┌────────┐
         │  BID   │◄───────►│  ASK   │
         │$175.48 │         │$175.52 │
         └────────┘         └────────┘
              │                   │
              └─────────┬─────────┘
                        │
                        ▼
                   ┌────────┐
                   │ СДЕЛКА │
                   │$175.50 │
                   └────────┘
```

### Факторы, влияющие на цену

1. **Финансовые результаты** — прибыль, выручка, рост
2. **Новости компании** — продукты, руководство, сделки
3. **Макроэкономика** — ставки ФРС, инфляция, ВВП
4. **Настроения рынка** — страх, жадность, тренды
5. **Действия крупных игроков** — покупки/продажи институционалов

<summary markdown="span"><b>Вопрос 1:</b> На какой бирже торгуются Apple, Microsoft и Tesla?</summary>

**Ответ:** NASDAQ — первая электронная биржа, фокусирующаяся на технологических компаниях.

</details>

<details>
<summary markdown="span"><b>Вопрос 2:</b> Во сколько открывается американский рынок по московскому времени?</summary>

**Ответ:** 16:30 МСК (основная сессия начинается в 9:30 по восточному времени США).

</details>

<details>
<summary markdown="span"><b>Вопрос 3:</b> Сколько компаний входит в индекс S&P 500 и какую долю рынка он охватывает?</summary>

**Ответ:** 500 компаний, охватывающих около 80% капитализации всего рынка США.

</details>

<details>
<summary markdown="span"><b>Вопрос 4:</b> Что такое Market Order и Limit Order?</summary>

**Ответ:**
- **Market Order** — покупка/продажа по текущей рыночной цене (мгновенное исполнение)
- **Limit Order** — покупка/продажа по указанной цене или лучше (может не исполниться)

</details>

<details>
<summary markdown="span"><b>Вопрос 5:</b> Что означает тикер AAPL?</summary>

**Ответ:** Apple Inc. — уникальный буквенный код компании на бирже.

</details>

<details>
<summary markdown="span"><b>Вопрос 6:</b> Чем отличается индекс Dow Jones от S&P 500?</summary>

**Ответ:**
- Dow Jones: 30 компаний, взвешен по цене акции
- S&P 500: 500 компаний, взвешен по капитализации, более репрезентативен

</details>
