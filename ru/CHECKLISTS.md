## 1. Чек-лист готовности к инвестированию

> Пройдите этот чек-лист ПЕРЕД началом инвестирования

### Финансовый фундамент

```
□ Нет долгов по кредитным картам (или ставка < 10%)
□ Нет других высокопроцентных долгов (> 7%)
□ Создана подушка безопасности
   □ Минимум 3 месяца расходов
   □ Идеально 6 месяцев расходов
   □ Деньги на высокодоходном savings account
□ Есть стабильный источник дохода
□ Расходы < доходов (положительный денежный поток)
```

### Знания и понимание

```
□ Понимаю, что такое акции и облигации
□ Понимаю, что такое ETF и индексные фонды
□ Знаю разницу между активным и пассивным инвестированием
□ Понимаю концепцию диверсификации
□ Понимаю, что инвестирование — это долгосрочно (10+ лет)
□ Готов(а) к временным падениям портфеля на 20-50%
□ Понимаю, что прошлая доходность не гарантирует будущую
```

### Цели и план

```
□ Определена главная цель инвестирования:
   □ Пенсия
   □ Финансовая независимость
   □ Крупная покупка (дом, образование)
   □ Другое: ________________
□ Определён горизонт инвестирования: ____ лет
□ Определена сумма для регулярных инвестиций: $____/месяц
□ Понимаю свою толерантность к риску:
   □ Агрессивный (80%+ акции)
   □ Умеренный (60-80% акции)
   □ Консервативный (< 60% акции)
```

### Итоговая проверка

```
□ Все пункты "Финансовый фундамент" выполнены
□ Все пункты "Знания" выполнены
□ Все пункты "Цели и план" заполнены

→ Если ДА — вы готовы открывать брокерский счёт!
→ Если НЕТ — сначала закройте пробелы
```

## 2. Чек-лист открытия брокерского счёта

### Выбор брокера

```
Для резидентов США:
□ Fidelity (рекомендуется для новичков)
□ Charles Schwab
□ Vanguard
□ Другой: ________________

Для нерезидентов:
□ Interactive Brokers (рекомендуется)
□ Другой: ________________

Критерии выбора (проверьте):
□ Нет комиссии за сделки с ETF
□ Нет минимального депозита (или устраивает)
□ Есть fractional shares (дробные акции)
□ Удобное мобильное приложение
□ Хорошие отзывы и надёжность
```

### Документы для открытия

```
□ Паспорт или водительские права
□ SSN (для резидентов США)
□ Адрес проживания (подтверждение)
□ Банковский счёт для пополнения
□ Электронная почта
□ Номер телефона
```

### Процесс открытия

```
□ Зашёл на сайт брокера
□ Нажал "Open Account" / "Открыть счёт"
□ Выбрал тип счёта:
   □ Individual Brokerage (обычный)
   □ Roth IRA (если подходит)
   □ Traditional IRA (если подходит)
   □ 401(k) rollover (если есть старый 401k)
□ Заполнил личные данные
□ Загрузил документы
□ Прошёл верификацию
□ Получил подтверждение открытия
```

### После открытия счёта

```
□ Привязал банковский счёт для переводов
□ Настроил двухфакторную аутентификацию (2FA)
□ Сохранил логин и пароль в надёжном месте
□ Сделал первый перевод на счёт
□ Дождался зачисления средств (1-3 дня)
```

### Для нерезидентов США (дополнительно)

```
□ Заполнил форму W-8BEN
□ Указал правильную страну налогового резидентства
□ Проверил применяемую ставку налога на дивиденды
□ Сохранил копию формы
□ Поставил напоминание обновить через 3 года
```

## 3. Чек-лист первой покупки ETF

### Подготовка

```
□ На счёте есть деньги (settled cash)
□ Определён ETF для покупки:
   □ VTI (весь рынок США) — рекомендуется
   □ VOO (S&P 500)
   □ VT (весь мир)
   □ Другой: ________________
□ Знаю текущую цену ETF (примерно)
□ Знаю, сколько хочу инвестировать: $________
```

### Процесс покупки

```
□ Вошёл в брокерский аккаунт
□ Нашёл ETF по тикеру (например, VTI)
□ Нажал "Buy" / "Trade" / "Купить"
□ Выбрал тип ордера:
   □ Market Order (рыночный) — рекомендуется для начала
   □ Limit Order (лимитный) — если хотите конкретную цену
□ Ввёл количество:
   □ В долларах (если есть fractional shares)
   □ В акциях
□ Проверил детали ордера
□ Подтвердил покупку
□ Получил подтверждение исполнения
```

### Сразу после покупки

```
□ Проверил, что ETF появился в портфеле
□ Проверил цену покупки и количество
□ Сделал скриншот/запись первой покупки (на память!)
```

### Настройка на будущее

```
□ Включил DRIP (реинвестирование дивидендов):
   □ Настройки → Dividends → Reinvest
□ Настроил автоматические покупки (если доступно):
   □ Recurring Investment
   □ Сумма: $_______
   □ Частота: еженедельно / ежемесячно
   □ Дата: _____ число месяца
□ Настроил автоматический перевод с банка (если нужно)
```

### Чего НЕ делать

```
□ НЕ проверять цену каждый час
□ НЕ паниковать при падении на 1-2%
□ НЕ продавать в первые дни/недели
□ НЕ менять стратегию без веской причины
□ НЕ рассказывать всем о своих инвестициях
```

## 4. Чек-лист "Что делать при падении рынка"

> Используйте этот чек-лист, когда рынок падает на 10%+
> и вы чувствуете панику

### Шаг 1: Остановитесь и подышите

```
□ Закрыл брокерское приложение
□ Сделал 10 глубоких вдохов
□ Напомнил себе: "Это временно"
□ Перечитал свой инвестиционный план
```

### Шаг 2: Проверка реальности

```
□ Мой горизонт инвестирования: ____ лет
   → Если > 5 лет: падение не имеет значения

□ Мне нужны эти деньги в ближайший год?
   □ НЕТ → Не продавать!
   □ ДА → Зачем они в акциях?

□ Изменились ли мои жизненные обстоятельства?
   □ НЕТ → Придерживаться плана
   □ ДА → Пересмотреть (но не в панике!)
```

### Шаг 3: Историческая перспектива

```
Напомни себе:
□ S&P 500 падал на 20%+ множество раз
□ Каждый раз рынок восстанавливался
□ Худшее время для продажи — на дне
□ Лучшие дни рынка часто следуют за худшими
□ Инвесторы, продавшие в 2008, пропустили рост 500%+
```

### Шаг 4: Что делать

```
✅ ДЕЛАТЬ:
□ Продолжать регулярные инвестиции (DCA)
□ Рассмотреть ребалансировку (купить акции дешевле)
□ Использовать tax-loss harvesting (если применимо)
□ Поговорить с другом-инвестором (не паникёром)
□ Перечитать истории инвесторов, переживших кризисы

❌ НЕ ДЕЛАТЬ:
□ Продавать в панике
□ Пытаться угадать дно
□ Читать панические новости
□ Менять стратегию под влиянием эмоций
□ Смотреть на портфель каждый день
```

### Шаг 5: Действия после падения

```
Если падение > 10%:
□ Проверить, есть ли свободные средства для покупки
□ Рассмотреть внеочередную покупку "на распродаже"

Если падение > 20%:
□ Проверить соотношение акции/облигации
□ Если облигаций стало > целевого — ребалансировать
□ Записать свои мысли и эмоции (полезно для будущего)

Если падение > 30%:
□ Это редкость! (2008, 2020)
□ Все действия выше +
□ Рассмотреть максимальные взносы в IRA/401(k)
□ Помнить: это лучшие возможности для покупок
```

### Мантры для кризиса

```
Повторять при панике:

"Время в рынке > тайминг рынка"

"Это падение — скидка на мои будущие покупки"

"Я инвестирую на 10+ лет, не на 10 дней"

"Продать сейчас = зафиксировать убыток"

"Stay the course" (Джон Богл)
```

## 5. Годовой чек-лист инвестора

> Выполняйте раз в год (например, в январе или в день рождения)

### Обзор портфеля

```
□ Проверил общую стоимость портфеля: $_________
□ Сравнил с прошлым годом: $_________ (+___%)
□ Проверил общую сумму инвестиций за год: $_________
□ Проверил полученные дивиденды: $_________
```

### Ребалансировка

```
Текущее распределение:
□ Акции США: _____%  (цель: _____%)
□ Международные: _____%  (цель: _____%)
□ Облигации: _____%  (цель: _____%)
□ Другое: _____%

□ Отклонение от цели > 5%?
   □ ДА → Ребалансировать
   □ НЕТ → Оставить как есть

□ Если ребалансирую:
   □ Продать: _________________ на $_______
   □ Купить: _________________ на $_______
   □ Или: направить новые взносы в отстающий класс
```

### Обзор стратегии

```
□ Мои цели изменились?
   □ НЕТ → Продолжать
   □ ДА → Скорректировать план

□ Мой горизонт изменился?
   □ Стал короче → Больше облигаций?
   □ Остался прежним → Продолжать

□ Моя толерантность к риску изменилась?
   □ Паниковал при падениях → Меньше акций
   □ Хотел больше акций при падении → Больше акций
   □ Всё устраивает → Продолжать
```

### Налоговая оптимизация

```
□ Проверил нереализованные убытки
   □ Есть убытки > $3,000 → Рассмотреть tax-loss harvesting
□ Проверил нереализованную прибыль
   □ Большая прибыль → Не продавать без нужды
□ Максимизировал взносы в налоговые счета?
   □ 401(k): вложил $_______ из $24,500 (2026)
      (+$8,000 catch-up в 50+, либо +$11,250 в 60-63 года,
       который ЗАМЕНЯЕТ $8,000, а не суммируется с ним)
   □ IRA: вложил $_______ из $7,500 (2026) (+$1,100 в 50+)
   □ HSA (если есть): вложил $_______ из $4,400 индивидуальный /
      $8,750 семейный (2026) (+$1,000 в 55+)
```

### Обновление данных

```
□ Проверил бенефициаров счетов
   □ Актуальны после изменений в семье
□ Обновил контактную информацию у брокера
□ Проверил форму W-8BEN (для нерезидентов)
   □ Действительна ещё ____ лет
   □ Нужно обновить? □
```

### Планирование на следующий год

```
□ Новая цель по ежемесячным инвестициям: $_______
□ Планируемые крупные расходы: $_______
□ Нужно скорректировать план?
□ Автоматические переводы настроены?
□ Дата следующего годового обзора: ___________
```

## 6. Чек-лист налоговой отчётности (США)

> Для резидентов США. Выполняйте в январе-апреле.

### Сбор документов (январь-февраль)

```
□ Дождался форм от брокера (приходят до 15 февраля):
   □ 1099-DIV (дивиденды)
   □ 1099-B (продажи)
   □ 1099-INT (проценты)
   □ Consolidated 1099

□ Собрал данные по взносам в IRA:
   □ Сумма взносов в Traditional IRA: $_______
   □ Сумма взносов в Roth IRA: $_______

□ Собрал данные по 401(k):
   □ Форма W-2 с информацией о взносах
```

### Заполнение декларации (февраль-апрель)

```
□ Выбрал способ подачи:
   □ Самостоятельно (TurboTax, H&R Block, FreeTaxUSA)
   □ С налоговым консультантом (CPA)

□ Указал доход от инвестиций:
   □ Дивиденды (обычные и квалифицированные)
   □ Прирост капитала (short-term / long-term)
   □ Проценты

□ Применил вычет за взносы в Traditional IRA (если подходит)
□ Указал иностранные налоги (для Foreign Tax Credit)
□ Проверил все цифры дважды
```

### Оптимизация

```
□ Использовал tax-loss harvesting?
   □ Убытки засчитаны против прибыли
   □ Оставшиеся убытки (до $3,000) против дохода

□ Проверил квалифицированные дивиденды
   □ Облагаются по ставке LTCG (0/15/20%)

□ Все продажи были long-term (> 1 года)?
   □ Если нет — помнить на будущее
```

### Подача и оплата

```
□ Подал декларацию до 15 апреля
   □ Или продлил до 15 октября (Form 4868)
□ Оплатил налоги (если должен)
□ Получил возврат (если полагается)
□ Сохранил копию декларации
□ Сохранил все подтверждающие документы (7 лет)
```

### Для нерезидентов

```
□ Форма W-8BEN заполнена и действительна
□ Налог на дивиденды удержан у источника
□ Проверил налоговое соглашение со своей страной
□ Отчитался о доходах в своей стране (если требуется)
```

## Как использовать чек-листы

```
1. РАСПЕЧАТАЙТЕ нужный чек-лист или скопируйте в заметки
2. ОТМЕЧАЙТЕ каждый пункт по мере выполнения
3. СОХРАНИТЕ заполненные чек-листы для истории
4. ПОВТОРЯЙТЕ годовой чек-лист каждый год
5. ОБРАЩАЙТЕСЬ к чек-листу при падении рынка!
```
