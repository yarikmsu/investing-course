## 2. DCA vs Единоразовая инвестиция

### Как работает DCA (Dollar-Cost Averaging)

```
Пример: $1,200 на год

Единоразово в январе:         DCA $100/месяц:
└── Купил 10 акций по $120    └── Покупает каждый месяц

Месяц   Цена    DCA покупает
─────────────────────────────
Янв     $120    0.83 акции
Фев     $100    1.00 акции
Мар     $80     1.25 акции   ← больше при падении
Апр     $90     1.11 акции
Май     $110    0.91 акции
Июн     $130    0.77 акции
Июл     $140    0.71 акции
Авг     $120    0.83 акции
Сен     $100    1.00 акции
Окт     $110    0.91 акции
Ноя     $120    0.83 акции
Дек     $130    0.77 акции
─────────────────────────────
Итого:          10.92 акции

Единоразово: 10.00 акций × $130 = $1,300
DCA:         10.92 акций × $130 = $1,420

DCA выиграл на +$120 (+9%) благодаря покупкам на падении!
```

### Когда DCA лучше, когда хуже

```
DCA ЛУЧШЕ при падающем или волатильном рынке:

Цена
$150 ┤
     │    ╭─╮
$120 ┤───╯   ╰───╮
     │           │    ╭───
$90  ┤           ╰───╯
     │
$60  ┼─────────────────────
     Янв  Мар  Май  Июл  Сен

DCA покупает больше акций на минимумах


Единоразово ЛУЧШЕ при растущем рынке:

Цена
$150 ┤              ╭────
     │          ╭───╯
$120 ┤      ╭───╯
     │  ╭───╯
$90  ┤──╯
     │
$60  ┼─────────────────────
     Янв  Мар  Май  Июл  Сен

Единоразовая покупка захватывает весь рост
```

### Исторически: Единоразово vs DCA

```
Исследование Vanguard (US, 1926-2011):

Примерно в 2/3 случаев (~67%) единоразовая инвестиция
победила DCA, в ~1/3 случаев DCA оказался лучше

НО! Средняя разница в итоговом капитале небольшая (~2%),
и это разовый разрыв за период, а не +2% годовых.

Вывод:
├── Если есть деньги сейчас → инвестируй сейчас
├── Если нет → DCA с зарплаты
└── DCA лучше для психологии (меньше стресса)
```

> 📖 Источник: [Vanguard "Cost averaging: Invest now or temporarily hold your cash?" (2023)](https://corporate.vanguard.com/content/dam/corp/research/pdf/cost_averaging_invest_now_or_temporarily_hold_your_cash.pdf)

## 5. Диверсификация и риск

### Как диверсификация снижает риск

```
Количество акций vs Риск:

Риск
(волатильность)
     │
100% ┤█
     │█
 80% ┤██
     │███
 60% ┤████
     │██████
 40% ┤████████████
     │████████████████████
 20% ┤████████████████████████████████████████ ← рыночный риск
     │                                         (нельзя устранить)
  0% ┼───────────────────────────────────────────

```

### Долгосрочные vs Краткосрочные налоги

```
$10,000 прибыли — сколько останется после налогов?

КРАТКОСРОЧНЫЕ (< 1 года):
├── Налог как обычный доход
├── Ставка 22-37% (зависит от дохода)
├── При 24%: $10,000 - $2,400 = $7,600
│   ████████████████████████████░░░░░░░░░ $7,600

ДОЛГОСРОЧНЫЕ (> 1 года):
├── Специальная ставка
├── 0%, 15% или 20% (зависит от дохода)
├── При 15%: $10,000 - $1,500 = $8,500
│   ██████████████████████████████████░░░ $8,500

Экономия: $900 просто за то, что подождали год!
```

### Tax-Loss Harvesting

```
Как это работает:

Январь: Купили VTI за $10,000
Июнь:   VTI стоит $8,500 (убыток $1,500)

ШАГ 1: Продаём VTI с убытком $1,500
ШАГ 2: Сразу покупаем ITOT (аналогичный ETF)
ШАГ 3: Убыток $1,500 уменьшает налоги

Налоговая экономия (при ставке 24%):
$1,500 × 24% = $360 экономии

⚠️ Важно: нельзя покупать "существенно идентичный"
   актив 30 дней до и после (Wash Sale Rule)

VTI → ITOT ✓ (разные провайдеры, разрешено)
VTI → VTI ✗ (идентичный актив, запрещено)
```

## Интерактивные калькуляторы

### Калькулятор сложного процента (формула)

```
Будущая стоимость = P × (1 + r)^n

P = начальная сумма
r = годовая доходность (в десятичных)
n = количество лет

Пример:
$10,000 × (1 + 0.10)^20 = $67,275
```

### Калькулятор регулярных инвестиций (формула)

```
Будущая стоимость = PMT × [((1 + r)^n - 1) / r]

PMT = ежемесячный взнос
r = месячная доходность (годовая / 12)
n = количество месяцев

Пример ($500/мес, 10%, 20 лет):
$500 × [((1 + 0.00833)^240 - 1) / 0.00833] = $382,846 (взносы в начале месяца)
```
