# TLDR: Инвестирование в США за 5 минут

{% include reviewed.html %}

> Краткое резюме всего курса на одной странице. Для тех, кто хочет суть без деталей.

## 🎯 Главное

```
1. Создайте подушку безопасности (3-6 месяцев расходов)
2. Погасите долги по кредитным картам
3. Откройте брокерский счёт (Fidelity, Schwab, или IBKR)
4. Купите VTI или VOO
5. Настройте автоматические покупки
6. Забудьте на 10-20 лет
```

## 📊 Во что инвестировать?

### Для новичков (один ETF):
```
VTI — весь рынок США (~3,500 компаний)
Expense Ratio: 0.03% (почти бесплатно)
```

### Простой портфель (2-3 ETF):
```
Молодой (25-40 лет):      Средний (40-55 лет):     Консервативный (55+):
├── VTI: 80%              ├── VTI: 60%             ├── VTI: 40%
└── BND: 20%              ├── VXUS: 20%            ├── VXUS: 20%
                          └── BND: 20%             └── BND: 40%
```

### Что это:
```
VTI  = Все акции США
VXUS = Международные акции
BND  = Облигации США
```

## 📋 5 правил инвестора

```
1. НЕ пытайтесь угадать рынок
   → Никто не знает, куда он пойдёт завтра

2. НЕ паникуйте при падениях
   → Падения временные, рост — долгосрочный тренд

3. Диверсифицируйте
   → ETF на весь рынок лучше отдельных акций

4. Инвестируйте регулярно
   → Каждый месяц одну и ту же сумму (DCA)

5. Думайте на 10+ лет вперёд
   → Краткосрочные колебания не имеют значения
```

## 📈 Чего ожидать?

```
Средняя историческая доходность S&P 500: ~10% годовых

При $500/месяц и 10% годовых:
├── Через 10 лет: ~$100,000
├── Через 20 лет: ~$380,000
├── Через 30 лет: ~$1,13 млн

⚠️ Это не гарантия! Рынок волатилен.
   Отдельные годы могут быть -20% или +30%.
   10% — номинальная доходность; реальная после
   инфляции ниже (~6–7%), а прогнозы на ближайшие
   10 лет — порядка 4–6% реальных.
```

## ⚠️ НЕ инвестируйте, если:

```
❌ Есть долги по кредитным картам
❌ Нет подушки безопасности
❌ Деньги нужны через 1-3 года
❌ Это последние сбережения
❌ Не готовы к временным падениям
```
