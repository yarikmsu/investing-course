## 🛤️ Пути прохождения

### Путь 1: Экспресс (2-3 часа)
```
TLDR → Быстрый старт → FAQ → Модуль 8
```
**Для кого:** Нетерпеливые, хотят начать быстро.
**Что пропустите:** Глубокое понимание налогов и стратегий.

### Путь 2: Стандартный (8-10 часов)
```
Модуль 0 → Модули 1-8 → EXERCISES
```
**Для кого:** Хотят глубокого понимания.
**Результат:** Полное понимание инвестирования в США.

### Путь 3: Для россиян
```
Модуль 0 → RUSSIA.md → Модуль 3 → Модуль 5 → Модуль 7
```
**Для кого:** Инвесторы из России с учётом санкций.
**Акцент:** Доступные брокеры, налоги РФ, ограничения.

### Путь 4: Для нерезидентов (кроме России)
```
Модуль 0 → NON-RESIDENTS.md → Модули 3-6 → Модуль 8
```
**Для кого:** Живущие за пределами США (кроме РФ).
**Акцент:** W-8BEN, ирландские ETF, налоговые соглашения.

### Путь 5: Продвинутый инвестор
```
Модуль 7 → ADVANCED.md → ETF-ANALYSIS → INVESTOR-STORIES
```
**Для кого:** Уже инвестируете, хотите оптимизировать.
**Акцент:** Tax-loss harvesting, Roth conversion, кейсы.

## 📖 Как пользоваться курсом

1. Начните с [Модуля 0](./module-00-preparation/) — убедитесь, что готовы
2. Изучайте модули последовательно или используйте "Быстрый старт"
3. Выполняйте практические задания в конце каждого модуля

## ⚠️ Важные замечания

> **Дисклеймер:** Данный курс носит образовательный характер и не является инвестиционной рекомендацией. Всегда проводите собственный анализ перед принятием инвестиционных решений. Инвестирование связано с рисками, включая возможную потерю капитала.

> **Актуальность:** Налоговые ставки, лимиты счетов и условия брокеров могут меняться. Проверяйте актуальную информацию перед принятием решений.
