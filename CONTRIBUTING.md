## Русский

Спасибо за интерес к улучшению курса! Мы приветствуем вклад от сообщества.

### Как помочь

#### 1. Сообщить об ошибке

- Откройте [Issue](https://github.com/yarikmsu/investing-course/issues/new)
- Опишите проблему: что не так, где находится, как воспроизвести
- Укажите, какая версия (RU или EN)

#### 2. Предложить улучшение

- Используйте [GitHub Discussions](https://github.com/yarikmsu/investing-course/discussions)
- Опишите идею и почему она будет полезна
- Приложите примеры, если возможно

#### 3. Исправить ошибку или добавить контент

1. Сделайте Fork репозитория
2. Создайте ветку: `git checkout -b fix/описание-изменения`
3. Внесите изменения
4. Создайте Pull Request

### Правила контента

| Что делать | Чего избегать |
|------------|---------------|
| Конкретные примеры с цифрами | Рекомендации конкретных акций |
| ETF с тикерами (VOO, VTI) | Обещания доходности |
| Пошаговые инструкции | Продвижение активного трейдинга |
| Предупреждения о рисках | Устаревшая информация без пометок |
| Дисклеймеры | Финансовые советы |

### Стиль

- **Русская версия (`ru/`)**: русский язык, понятный широкой аудитории
- **English version (`en/`)**: clear, beginner-friendly English
- Короткие абзацы, списки, таблицы
- Markdown форматирование
- Эмодзи по стандарту: 💡 совет, ⚠️ риск, ✅ подтверждение, 📊 данные

### Синхронизация версий

При изменении контента:
1. Обновите основную версию (RU или EN)
2. Отметьте в PR, что нужен перевод
3. Если можете — переведите сами

### Проверка перед PR

- [ ] Проверены орфография и грамматика
- [ ] Ссылки работают
- [ ] Формат соответствует остальным файлам
- [ ] Добавлены дисклеймеры где нужно
- [ ] Данные актуальны (с указанием даты)

## English

Thank you for your interest in improving the course! We welcome contributions from the community.

### How to Help

#### 1. Report an Error

- Open an [Issue](https://github.com/yarikmsu/investing-course/issues/new)
- Describe the problem: what's wrong, where it is, how to reproduce
- Specify which version (RU or EN)

#### 2. Suggest an Improvement

- Use [GitHub Discussions](https://github.com/yarikmsu/investing-course/discussions)
- Describe your idea and why it would be useful
- Include examples if possible

#### 3. Fix an Error or Add Content

1. Fork the repository
2. Create a branch: `git checkout -b fix/change-description`
3. Make your changes
4. Create a Pull Request

### Content Guidelines

| Do | Don't |
|----|-------|
| Specific examples with numbers | Recommend specific stocks |
| ETFs with tickers (VOO, VTI) | Promise returns |
| Step-by-step instructions | Promote active trading |
| Risk warnings | Use outdated info without notes |
| Disclaimers | Give financial advice |

### Style

- **Russian version (`ru/`)**: Russian accessible to general audience
- **English version (`en/`)**: clear, beginner-friendly English
- Short paragraphs, lists, tables
- Markdown formatting
- Standard emojis: 💡 tip, ⚠️ risk, ✅ check, 📊 data

### Version Synchronization

When changing content:
1. Update the primary version (RU or EN)
2. Note in PR that translation is needed
3. Translate yourself if you can

### Pre-PR Checklist

- [ ] Spelling and grammar checked
- [ ] Links work
- [ ] Format matches other files
- [ ] Disclaimers added where needed
- [ ] Data is current (with date noted)
