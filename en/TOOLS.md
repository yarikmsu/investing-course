## 1. Brokers

### For US Residents

| Broker | Commissions | Minimum | Features |
|--------|-------------|---------|----------|
| **Fidelity** | $0 | $0 | Excellent support, fractional shares |
| **Charles Schwab** | $0 | $0 | Wide selection, banking services |
| **Vanguard** | $0 | $0 | Creators of index investing |
| **Robinhood** | $0 | $0 | Simple interface (for beginners) |
| **M1 Finance** | $0 | $100 | Automatic rebalancing |

```
Recommendation for beginners:
├── Fidelity — best balance of features and simplicity
├── Schwab — if you need banking services
└── Vanguard — for committed Bogleheads

⚠️ About Robinhood:
├── Simple interface attracts beginners
├── BUT: gamification can encourage frequent trading
├── Confetti, notifications — psychological tricks
├── For long-term investing, prefer Fidelity/Schwab
└── If you use it — disable notifications!
```

### For Non-US Residents

| Broker | Countries | Features |
|--------|-----------|----------|
| **Interactive Brokers** | 200+ countries | Main choice for non-residents |
| **Saxo Bank** | Europe, Asia | European broker |
| **eToro** | 100+ countries | Social trading |

```
Recommendation for non-residents:
└── Interactive Brokers — the only serious choice
    ├── Low commissions
    ├── Access to all markets
    └── W-8BEN online
```

### How to Use Portfolio Visualizer

```
Main features:
├── Backtest Portfolio — test on historical data
├── Asset Correlations — asset correlation
├── Monte Carlo — future modeling
├── Factor Analysis — factor analysis
└── Asset Allocation — optimal distribution

Example: compare VTI and VOO over 10 years
1. Backtest Portfolio → Asset Allocation
2. Enter tickers and weights
3. Select period
4. Analyze!
```

## Quick Start: Minimum Toolkit

```
For a beginning investor, this is enough:

1. BROKER
   └── Fidelity (US) or Interactive Brokers (non-US)

2. INFORMATION
   └── etf.com — for studying ETFs

3. ANALYSIS
   └── portfoliovisualizer.com — for backtests

4. EDUCATION
   └── bogleheads.org — philosophy and forum

5. BOOK
   └── "The Little Book of Common Sense Investing"

THAT'S IT. Everything else — as needed.
Don't overcomplicate!
```

## Warnings

```
🚩 RED FLAGS — avoid:

1. "Guaranteed returns of 50%+ per year"
2. Paid signals and groups
3. "Secret strategies" for money
4. Courses from "millionaire traders"
5. Any schemes with pyramid structure
6. "Unique" investment opportunities
7. Pressure to make quick decisions

Rule: if it sounds too good — it's a scam.
```
