## Learning Paths

### Path 1: Express (2-3 hours)
```
TLDR → Quick Start → FAQ → Module 8
```
**For whom:** Impatient, want to start quickly.
**What you'll miss:** Deep understanding of taxes and strategies.

### Path 2: Standard (8-10 hours)
```
Module 0 → Modules 1-8 → EXERCISES
```
**For whom:** Want deep understanding.
**Result:** Complete understanding of US investing.

### Path 3: For Non-US Residents
```
Module 0 → NON-RESIDENTS.md → Modules 3-6 → Module 8
```
**For whom:** Living outside the US.
**Focus:** W-8BEN, Irish ETFs, tax treaties.

### Path 4: Advanced Investor
```
Module 7 → ADVANCED.md → ETF-ANALYSIS → INVESTOR-STORIES
```
**For whom:** Already investing, want to optimize.
**Focus:** Tax-loss harvesting, Roth conversion, case studies.
