# ℹ️ About This Course

Information about the course, sources, and changelog.

## Course Philosophy

This course is based on **passive investing** principles (Bogleheads):

- 📊 **Index funds** as the portfolio core
- ⏳ **Long-term** investing (10+ years)
- 💰 **Low costs** — minimize fees
- 🧘 **Simplicity** — 2-4 ETFs are enough
